# GPT 整理指令 · 把访谈录音转成知识条目

> 用法：把这段指令 + 访谈语音的**转录文字**一起发给 GPT。
> GPT 的角色是**加工真材料**，不是无中生有。

---

## 把下面整段发给 GPT（连同转录文字）

```
你是我的内容整理助手。我会给你一段「学长/学姐人生访谈」的语音转录（口语、零散、可能有重复和跑题）。
请把它整理成一组「知识条目」，供一个 AI 学长分身使用。

【最重要的铁律】
1. 只能使用转录里**真实出现过**的信息。**严禁编造、脑补、补全任何事实**——
   时间、地点、学校、专业、薪资、人物、情节，凡是转录里没有的，一律不许加。
2. 如果某块内容很薄或缺失，**不要替他编**。在末尾「待补清单」里列出来，让我回去问本人。
3. 保留他的**原话语气和具体细节**（数字、专有名词、那句话原本的说法）。
   宁可保留口语的真实感，也不要改写成通顺但失真的"攻略腔"。

【怎么切分】
- 一条知识条目 = 一个独立的小主题/一个故事，**原子化**，不要把一大段塞成一条。
- 每条给一个**具体的标题**，用他真实的事，不要用干巴巴的分类名。
  - 好标题：「异地三年后我们还是分了」「读研第二年我差点退学」「第一个月工资我给我妈转了五千」
  - 坏标题：「感情经历」「读研感受」「职场体会」
- 优先保留并突出这几类（这是产品价值所在）：
  读研/工作的**真实落差**、**毕业去向与值不值**、**感情/家庭的变化**、
  **后悔与复盘**、**对人生/成功/金钱的思考**、**计划外的转折**。
- 纯攻略类（怎么背书、怎么投简历）合并成 1-2 条即可，不用展开。

【脱敏】
- 模糊掉能认出**具体个人**的信息（真实姓名、罕见的具体单位/导师名等），保留"哪类学校/哪类公司/什么量级"。
- 薪资、家庭等敏感内容予以保留但提醒我"上线前需本人确认是否公开"。

【输出格式】
对每一条，输出：
- 标题：
- 正文：（第一人称，保留他的语气；只含转录里的真实信息）
- 归属线：（学业/事业/生活/感情/家庭/自我 之一）

最后单独给两块：
- 【待补清单】：哪些主题太薄或缺失，建议我回去补问（附 1-2 个具体追问）
- 【需本人确认】：哪些敏感内容上线前要征得同意
```

---

## 整理完之后

1. 你拿到的条目，逐条核对——**凡是你不记得他说过的，删掉**（防 GPT 偷偷补全）。
2. 「待补清单」就是你**第二次找他**要补的料。
3. 确认无误，填进**一个** Agent。这一个真·够格的，比现在 600 个空壳都顶用。

---

## ⚠️ 不要做的事

- ❌ 不要让 GPT「帮我把 600 个 Agent 都填上人生故事」——那是批量造假，等于把刚挖好的护城河填平，做出来还是 DeepSeek 也能产的通用品。
- ✅ GPT 只在「真录音 → 知识条目」这一步出现。**原料必须来自真人。**
