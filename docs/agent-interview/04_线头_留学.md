## 几扇门（线头池）

**申请/落地**
- 拿到 offer 那天 **vs 真正落地后**的落差。
- 一个人在异国**最孤独 / 最崩溃**的时刻。
- 语言、文化、**融不进去**的真实体验。

**之后（重点）**
- 钱：到底花了多少、**值不值**、家里的压力多大？
- 毕业后**留下还是回国**？怎么纠结的，结果如何？
- 出去一趟，你的**三观被改了哪一块**？
- 你**后悔的一个选择**(选校 / 专业 / 国家)。
- 如果重来，你**还出国吗**？

**感情 / 家庭 / 自我**（哪条亮聊哪条）
- 你在国外的**感情 / 异地 / 文化差异**，发生过什么？
- 隔着时差和距离，你和**父母**的关系变近还是变远？
- 一个人在外面这些年，你最大的**改变**是什么？
- 现在的你，是出国前那个你想成为的人吗？

---

## 示例

> 他："落地第一周我天天哭。"
> 你："**然后呢？**" → "听不懂、没朋友，连买菜都难"
> 你："**那一刻心里在想什么？**" → "想我爸妈花这么多钱，送我来受罪"
> 你："**这事你跟他们说过吗？**" → "没有，报喜不报忧"
> → 拐进 **家庭线 + 钱 + 自我线**。
