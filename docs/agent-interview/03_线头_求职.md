## 几扇门（线头池）

**找工作/职场**
- 从投简历到拿 offer，最**颠覆认知**的一件事。
- 一次面试的**社死或高光**时刻。
- 入职后发现「**跟想的完全不一样**」的那个瞬间。
- 加班 / 裁员 / 职场政治，你**真实**经历过什么。
- 你**后悔签**的那个 offer，或**拒了又庆幸**的那个。

**之后（重点）**
- **第一个月工资到手**，你做了什么、什么感觉？
- 你学的东西，工作里**真用得上吗**？哪些有用、哪些白学？
- 钱变多了，但你**失去了**什么？
- 你现在**还信「努力就有回报」**吗？

**生活 / 感情 / 家庭 / 自我**（哪条亮聊哪条）
- 工作之后，你的**生活状态**最大的变化是什么？现在一天怎么过？
- 上班之后，你的**感情**有什么变化？(没时间/异地/圈子变小/标准变了…)
- 工作了、能挣钱了，你和**爸妈**的关系变了吗？
- 走到现在，你对「成功」「值得」的看法，变了吗？

---

## 示例

> 他："我拿了大厂 offer，入职三个月就想跑。"
> 你："**然后呢？**" → "每天改需求改到凌晨"
> 你："**那一刻心里在想什么？**" → "想这是不是我要的生活"
> 你："**有没有某个具体瞬间让你突然意识到？**" → "有天凌晨打车，看到我爸发来一条消息……"
> → 拐进 **家庭线 + 自我线**。
